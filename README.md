# Flappy Bird (Python)

A lightweight Flappy Bird clone built with Pygame.

## Requirements

- Python 3.9+

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Controls

- **Space** or **Up Arrow**: Flap
- **R**: Restart after game over
- **Esc** or close window: Quit
